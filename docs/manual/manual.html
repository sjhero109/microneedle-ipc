1. 시스템 개요

마이크로니들 IPC는 토출기 5대(약액부 D1~D3, 기저부 B1~B2)의 IPC 중량을 기록하고, 기록이 쌓일 때마다 다음에 쓸 Pulse(약액부) 또는 Speed(기저부)를 추천하는 웹 앱입니다. PC와 휴대폰 브라우저에서 같은 주소로 접속하며, 모든 기록은 서버에 저장되어 접속한 모든 화면에 실시간으로 반영됩니다.

1.3 IPC 진행 흐름

  1. 배치를 시작하거나 기존 배치를 불러옵니다. 약액부는 함량(%)을 넣으면 목표 중량이 자동 환산됩니다.
  2. 생산 전 세팅은 트레이번호 0, 토출 개시 IPC는 1, 이후 공정 중 IPC는 해당 트레이번호로 저장합니다.
  3. 저장할 때마다 다음 Pulse·Speed 추천값이 입력란에 자동으로 들어갑니다. 장비에 그 값을 넣고 다음 IPC를 진행합니다.
  4. 공정이 끝나면 배치 완료를 누르고, 결과 탭에서 엑셀이나 보고서를 출력합니다.

2. 시작하기 — 가입, 로그인, 비밀번호

2.1 회원가입 작업자

  1. 로그인 화면에서 회원가입을 누릅니다.
  2. 이름과 이메일을 입력하고 회원가입을 누릅니다. 비밀번호는 입력하지 않습니다.
  3. "가입 신청이 접수되어 있습니다"가 보이면 관리자 승인을 기다립니다.
초기 비밀번호는 dw1234입니다. 관리자가 승인한 뒤 dw1234로 처음 로그인하면 새 비밀번호를 정하는 화면이 나옵니다. 승인 후 되도록 바로 로그인해 비밀번호를 바꾸세요.

2.2 첫 로그인과 비밀번호 변경

초기 비밀번호(dw1234)로 로그인하면 아래 화면만 나옵니다. 지금 비밀번호에 dw1234, 새 비밀번호(6자 이상)를 두 번 입력하면 바로 IPC 화면으로 들어갑니다. 평소에는 머리글의 비밀번호 변경으로 언제든 바꿀 수 있습니다.

2.3 로그인 보호

  • 5회 연속 실패하면 계정이 잠깁니다. 일반 사용자는 관리자에게 잠금 해제를 요청합니다.
  • 관리자 계정이 잠기면 등록된 이메일로 비밀번호 재설정 메일이 자동으로 발송됩니다. 메일의 링크로 비밀번호를 새로 정해 로그인하면 잠금이 풀립니다.
  • 자동 로그아웃: 화면을 누르거나 키를 입력하지 않은 채 설정된 시간(기본 15분)이 지나면 로그아웃됩니다. 시간은 관리자가 정합니다(5.8절).
  • 로그인, 로그아웃, 실패, 잠금, 해제는 모두 Audit trail에 남습니다.

3. 작업자 — IPC 진행

3.1 배치 시작과 불러오기

  1. 기존 배치 불러오기에서 진행 중인 배치를 고르면 바로 열립니다. 완료된 배치는 이 목록에 없고 결과 탭에서만 봅니다.
  2. 새 배치는 제품명(레시피), 배치번호, 제조일자, 약액부·기저부명, 약액부 함량(%), 약액부 IPC 배수를 입력하고 배치 시작을 누릅니다.
항목설명
약액부 함량(%)목표 중량 = 레시피 기준 중량(함량 100%) × 100 ÷ 함량. 예: 기준 6.11 mg, 함량 98.5% → 6.203 mg. 50~150% 사이만 입력됩니다. 기저부 목표는 함량과 무관합니다.
약액부 IPC 배수같은 Pulse로 몇 번 토출해 합산 중량을 잴지(예: 3회). 판정과 계산은 합계 ÷ 횟수인 1회분으로 합니다.

3.2 IPC 입력

  1. 트레이번호를 입력합니다. 같은 번호로 여러 번 저장하면 1-1, 1-2처럼 회차가 자동으로 붙습니다.
    • 0 = 생산 전 세팅(트레이 없이 측정)
    • 1 = 토출 개시 IPC
    • 그 밖의 번호 = 공정 중 IPC(해당 트레이)
  2. Pulse·Speed 칸에는 추천값이 미리 들어 있습니다. 장비에 실제로 넣은 값과 같은지 반드시 확인하고, 다르면 실제 값으로 고칩니다.
  3. 중량을 입력합니다. 약액부 IPC 배수가 3회면 칸 이름이 "3회 합계 (mg)"이고, 3회 토출 합계를 넣습니다.
  4. 저장 전에 측정값(1회분), 편차, 적합 여부, 저장 후 다음 추천값이 미리 표시됩니다. 확인 후 저장을 누릅니다.
추천값 사용: 적합 범위 안이어도 IPC마다 조정 목표(기본 103%)를 따라가도록 추천합니다. 저장하면 다음 추천값이 입력란에 자동으로 들어가고, 위쪽 큰 숫자도 같은 값입니다. 다른 사람이 같은 토출기에 저장해 추천값이 바뀌었다면 Pulse에 적용을 눌러 입력란을 맞춥니다.

판정 색상

표시뜻 (목표 대비 편차)
표시 없음±2% 이내
주의(노랑)2% 초과 ~ 5%
경고(빨강)5% 초과 ~ 10%
이탈(보라)10% 초과

적합 기준(기본 ±5%)과 경고 구간은 레시피에서 정합니다. "재측정 권장"이 뜨면 예상 범위를 크게 벗어난 값이므로 다시 재 보고 저장하세요.

추이 그래프 읽기

  • 점 = 측정값(색은 판정 구간), 빈 원 = 테스트·제외 기록, 파란 선 = 추정 수준, 아래 파란 눈금 = Pulse·Speed를 바꾼 지점
  • 왼쪽 축은 중량(mg), 오른쪽은 비율(100%, 103%, ±5%)입니다. 축은 계산에 쓰는 기록이 모두 보이는 범위로 자동 확대됩니다.
  • 점을 누르거나 마우스를 올리면 측정·추정 중량과 Pulse 값이 보입니다.

3.3 테스트 모드

기기 점검이나 시험 토출처럼 기록은 남기되 추천 계산에는 넣지 않을 값은 테스트 모드에서 저장합니다.

  • 체크는 배치에 저장되어 탭을 옮기거나 다시 로그인해도 유지되고, 그 배치를 보는 모든 사람에게 똑같이 적용됩니다.
  • 켜진 동안에는 누가 저장하든 테스트 기록이 됩니다.
테스트가 끝나면 반드시 체크를 끄세요. 켜 둔 채로 생산을 이어가면 다른 작업자의 실제 IPC도 테스트로 저장됩니다.

3.4 정보 수정

항목바꾸면
약액부 함량목표 중량이 다시 환산되고, 이후 저장하는 IPC부터 새 목표로 판정·추천합니다. 이미 저장한 기록의 판정은 그대로입니다.
약액부 IPC 배수이후 기록부터 새 횟수로 1회분을 계산합니다. 이전 기록은 저장 당시 횟수 그대로이며, 3회 합산 기록을 1회 기록보다 더 신뢰해 계산합니다.
조정 목표(약액부·기저부)추천값이 맞추는 비율(%)입니다. 적합 범위(기본 95~105%) 안에서만 정할 수 있고, 적합 판정 기준은 바뀌지 않습니다.

모든 변경은 Audit trail에 "배치 정보 변경"으로 남습니다.

3.5 기록 확인과 정정 요청

카드 아래 기록 표의 줄(또는 결과 탭의 기록)을 누르면 상세 화면이 열립니다.

  1. 정정할 항목(트레이번호 / Pulse·Speed / 합산 중량)을 고릅니다. 버튼에 현재 값이 함께 보입니다.
  2. 정정할 값과 사유(필수)를 넣고 정정 요청을 누릅니다.
  3. 관리자가 승인하면 값이 바뀌고 판정도 다시 계산됩니다. 승인·반려 결과는 알림으로 받습니다(6.1절).

기록은 삭제할 수 없습니다. 잘못 넣은 값은 정정으로, 쓰지 않을 값은 관리자의 "계산에서 제외"로 처리합니다.

3.6 배치 완료와 다시 열기

  • 배치 완료 → 완료 확정을 누르면 IPC 탭에서 더 이상 불러오거나 기록할 수 없고, 결과 탭에서만 볼 수 있습니다.
  • 완료한 배치를 다시 이어가야 하면 결과 탭에서 사유를 적고 다시 열 수 있습니다(작업자도 가능).

4. 작업자 — 결과와 보고서

4.1 결과 탭

배치를 누르면 배치 정보, 토출기별 요약(IPC 횟수, 적합·부적합, 평균 중량, Pulse·Speed 변화)과 그래프, 전체 기록이 나옵니다.

  • 엑셀 내보내기: IPC 기록, 배치 요약, 정정 이력, Audit trail 4개 시트로 저장합니다. 목록 화면의 "조회된 배치 엑셀 내보내기"는 조회된 배치를 한 파일로 묶습니다.
  • IPC 탭에서 열기: 진행 중인 배치를 IPC 탭으로 엽니다.

4.2 배치 보고서

보고서를 누르면 A4 보고서 화면이 열리고, 인쇄 · PDF 저장으로 인쇄하거나 PDF로 저장합니다(출력은 Audit trail에 남음).

구역내용
결론·지표토출기별 최종 판정, IPC 총·적합률·평균 편차·최대 이탈·첫 적합까지 가장 오래 걸린 토출기·조정 횟수
토출기별 통계n, 평균, SD, RSD, 최소·최대, 편차 범위, 적합, 첫 적합, Cpk(참고), Pulse·Speed 시작→최종

인쇄 설정: 용지 A4, 여백 기본값, 배경 그래픽 켜기. Cpk는 IPC마다 Pulse를 조정하는 공정 특성상 참고값입니다.

4.3 계산 로직 탭

추천값을 어떻게 계산하는지와 토출기별 현재 추정값(사전값 기준, 감도, 흔들림, 다음 반영 비율)을 보여 줍니다.

  • 중량 = 기준 수준 + 감도 × (Pulse − 기준 Pulse)로 보고, IPC마다 측정값과 예상값의 차이를 반영 비율만큼 반영해 수준을 고칩니다.
  • 과거 배치 기록은 출발점으로 쓰고, 새 배치의 첫 IPC는 거의 그대로 받아들여 그 배치의 출발점으로 삼습니다. 이후 기록이 쌓일수록 안정됩니다.
  • 추천값 = 현재 값 + (목표 × 조정 목표 − 현재 추정 중량) ÷ 감도

5. 관리자 기능 관리자

관리자 탭에는 레시피, 데이터 가져오기, 정정·이상치 검토, Audit trail, 사용자, 설정이 있습니다. 중요한 변경은 저장 전에 비밀번호를 한 번 더 확인합니다.

5.1 사용자 승인과 관리

기능설명
승인가입 신청자의 승인을 누르면 사용할 수 있습니다. 승인 후 사용자는 dw1234로 첫 로그인해 비밀번호를 바꿉니다.

5.2 레시피

제품(레시피)별로 아래 값을 정합니다. 레시피를 바꾸면 이후 시작하는 배치부터 적용됩니다.

  • 약액부 목표 중량(함량 100% 기준, 1회분), 기저부 목표 중량
  • 기본 약액부명·기저부명, 약액부 IPC 배수 기본값, Pulse·Speed 최소 단위
  • 적합 하한·상한(목표 대비 %), 조정 희망 비율(기본 103%), 경고 기준점과 노랑·빨강·보라 경고 시작값(±2/5/10%)

5.3 정정 승인과 알림

작업자가 정정을 요청하면 관리자 화면 오른쪽 위에 알림이 뜨고, 종 아이콘과 관리자 탭에 대기 건수가 표시됩니다.

승인할 수 있는 곳은 세 군데입니다. 어디서 처리하든 결과는 같고 Audit trail에 남습니다.

  1. 알림 목록(종 아이콘): 검토 의견을 적고 승인·반려
  2. 기록 상세: 승인 대기 요청 아래의 승인·반려 버튼
  3. 관리자 → 정정·이상치 검토: 대기 건이 있으면 관리자 탭을 열 때 이 화면이 먼저 열림

바로 정정(관리자): 기록 상세에서 관리자는 요청과 승인을 한 번에 처리할 수 있습니다. 트레이번호 0 이상, Pulse·중량은 0보다 커야 합니다.

5.4 이상치 제외와 테스트 기록 편입

  • 계산에서 제외: 기록 상세에서 사유를 적고 제외하면 기록은 남고 추천 계산에서만 빠집니다. 제외 취소도 가능합니다. 실수로 일반 저장한 테스트 값도 이 방법으로 처리합니다.
  • 테스트 기록 편입: 테스트로 저장한 기록을 계산에 넣으려면 기록 상세의 "계산에 편입" 또는 결과 탭의 "테스트 기록 N건 계산에 편입"을 누릅니다.

5.5 데이터 가져오기

과거 토출 기록 엑셀(토출기별 열: 회차·PULSE·중량)을 배치로 가져와 추천 계산의 과거 기준으로 씁니다. 시트를 고르고 미리보기를 확인한 뒤 가져옵니다.

5.6 Audit trail

로그인·로그아웃, IPC 저장, 배치 시작·변경·완료, 테스트 모드, 정정, 제외, 사용자·레시피·설정 변경, 엑셀·보고서 출력을 시각·사람·권한과 함께 기록합니다. 관리자는 전체를, 작업자는 본인 기록만 봅니다. 기록은 수정·삭제할 수 없습니다.

5.7 설정 — 자동 로그아웃

5~720분 사이 정수로 정합니다. 저장하면 이미 로그인한 모든 화면에도 바로 적용됩니다. 서버에 아직 올라가지 않은 저장이 있는 동안은 자동 로그아웃을 미룹니다.

6. 알림, 연결 상태, 휴대폰 사용

6.1 알림

  • 작업자: 내가 낸 정정 요청이 승인·반려되면 오른쪽 위에 10초간 알림이 뜨고, 종 아이콘에 확인하지 않은 건수가 표시됩니다. 종을 누르면 "내 정정 요청 결과"(최근 20건)가 나옵니다.
  • 관리자: 새 정정 요청이 오면 알림이 뜨고, 종 목록에서 바로 승인·반려합니다.
  • 알림은 앱을 열어 둔 동안에만 뜹니다. 휴대폰 푸시나 메일은 보내지 않습니다.

6.2 실시간 반영과 인터넷 연결

  • 누가 저장하든 접속한 모든 화면에 새로고침 없이 1~2초 안에 반영됩니다. 단, 입력 중인 칸은 바뀌지 않습니다.
  • 인터넷이 끊기거나 서버가 저장을 받지 못하면 화면 맨 위에 빨간 배너("서버 저장 대기 N건")가 뜹니다. 다시 연결되면 자동으로 올라갑니다.
배너가 떠 있는 동안 창을 닫거나 새로고침·로그아웃하면 대기 중인 값이 사라집니다. 앱이 경고를 띄우지만, 연결이 불안정할 때는 기록서에 먼저 적고 연결된 뒤 입력하세요. 끊겼다가 올라간 기록의 저장 시각은 서버가 받은 시각입니다.

6.3 휴대폰 사용

휴대폰에서도 같은 주소로 같은 기능을 씁니다. 토출기 카드는 제목을 눌러 접고 펼 수 있고, 접어도 추천값은 항상 보입니다.

7. 자주 묻는 질문과 문제 해결

상황해결
저장 버튼이 눌리지 않음트레이번호·Pulse·중량 세 칸이 모두 숫자로 채워졌는지 확인하세요. 배치가 완료 상태면 저장할 수 없습니다.
"트레이번호가 직전 기록보다 작습니다"참고 문구이며 저장은 됩니다. 트레이 0(세팅)과 테스트·제외 기록은 비교하지 않습니다.
같은 트레이를 여러 번 측정트레이번호에 같은 숫자만 넣으면 1-1, 1-2처럼 자동으로 구분됩니다. 1-1, 1.1처럼 직접 쓰지 마세요.
테스트로 저장해야 했는데 일반으로 저장함관리자에게 "계산에서 제외"를 요청하세요(사유: 테스트 측정 – 체크 누락).
추천값이 이상하게 크게 바뀜입력한 Pulse가 장비 값과 같은지, 3회 합계 칸에 1회 값을 넣지 않았는지 확인하세요. 같은 Pulse로 두 번 재서 흔들림을 확인하고, 흔들림이 크면 IPC 배수를 3회로 늘리세요. 판단이 어려우면 결과 탭 보고서의 고찰을 참고하세요.
함량을 잘못 입력함정보 수정에서 바로 고치세요. 이미 저장한 기록의 판정은 저장 당시 목표로 남습니다.
계정이 잠김일반 사용자는 관리자에게 잠금 해제를, 관리자는 이메일로 받은 재설정 링크를 이용하세요.
비밀번호를 잊음관리자에게 비밀번호 초기화(dw1234) 또는 재설정 메일 발송을 요청하세요.
자꾸 로그아웃됨자동 로그아웃 시간이 지났기 때문입니다. 관리자가 설정에서 늘릴 수 있습니다.
보고서 인쇄 시 색이 안 나옴인쇄 창에서 "배경 그래픽"을 켜세요. 쪽 번호는 최신 Chrome·Edge에서 표시됩니다.

8.1 용어

IPC 배수한 번의 IPC에서 같은 값으로 토출해 합산하는 횟수(약액부만). 계산은 1회분으로 합니다.
